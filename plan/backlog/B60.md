# B60: Launch to first pixels takes 1.2–2 s on Windows

Status: open

- **Found:** M0's Windows spike (date not recorded); moved here from the README's
  "Open questions" when the plan was split (2026-10-25)
- **Where:** sheaf-app startup on Windows (GPUI's platform init)
- **Severity:** annoyance (slow)
- **What happens:** launch to first pixels takes 1.2–2 s on Windows
  (DirectX 11, Intel UHD 620); opening the PDF itself takes about 10 ms.
- **Expected:** a launch as quick as on Linux.
- **Repro:** time a cold launch with a small PDF on Windows.
- **Notes:** investigate platform init. GPUI is pre-1.0; the README's old
  "GPUI risk" question is otherwise settled (GPUI is in use since M0).
