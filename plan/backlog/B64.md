# B64: CI's paths filter still names todos/ and skips only the root's Markdown

Status: open

- **Found:** 2026-10-26, Claude, during the pdf-lint item's slice 1
- **Where:** `.github/workflows/ci.yml`, `on.push.paths` (`&code`, which
  `pull_request` reuses)
- **Severity:** annoyance
- **What happens:** the filter leaves out `!todos/**`, a folder gone
  since #53, and `!*.md`, which matches only the repository root's
  Markdown. A change to `plan/` alone, all Markdown, runs the whole
  matrix on ubuntu, macOS and Windows.
- **Expected:** a change only to the plan's Markdown runs nothing, as a
  change only to `docs/` doesn't, unless a test reads it.
- **Repro:** a PR that touches only `plan/**/*.md` starts the CI jobs.
- **Notes:** `!plan/**` in place of `!todos/**` would do, and maybe
  `!**/*.md` in place of `!*.md`, keeping the two docs a test reads
  (`docs/document-model.md`, `docs/plugins.md`). `scripts/check-plan.py`
  runs in `just precommit`, so the plan stays checked locally.
