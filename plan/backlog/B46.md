# B46: The Arlington carried rule matches a merged object's finding against every object of the sources

Status: open

- **Found:** 2026-10-24, the Arlington checks' review (F22)
- **Where:** `answered` in `crates/sheaf-ops/tests/arlington.rs`, the
  carried rule `sorted_out` and the default tests' `clean_against` both
  apply, which is pdf-lint's `Report::beyond`
- **Severity:** a gap in a test-only check
- **What happens:** a finding in an object sheaf merged over a source's
  dictionary is carried when any object of a source has a like one (the
  same table, key, rule and value, numbers aside; a `missing` finding's
  value is always "absent", and `too-new` compares none), not only the
  object it was emitted over. A page that loses its `/MediaBox` or
  `/Resources` in a save is missed when some page of the source lacks one
  too.
- **Expected:** carried only from the source object the merged one was
  emitted over.
- **Repro:** `a_merged_objects_finding_is_carried_from_any_object_of_a_source`
  (`crates/sheaf-ops/tests/arlington.rs`) pins the gap in `answered`, and
  flips with the fix, which goes there.
- **Notes:** Built objects are never carried, so sheaf's own writers
  aren't affected. On pdf-lint 0.1.0 the corpus tier carries 120,775
  findings (4,666 `missing`; 103,793 of them `deprecated`, which
  pdf-lint finds where sheaf's checker found 2,197); on sheaf's checker
  it carried 18,669 (4,539 `missing`). pdf-lint documents the same rule
  for `beyond` and has two that carry per place: `Report::since`, by
  object number, for an Append (an update keeps its objects' numbers),
  and `Report::by_path`, by where the walk reached the finding (with
  `Options::paths`), for a Rewrite. Or record each merged object's
  source object (`lint::written` in `crates/sheaf-ops/tests/lint/` has
  each key: a page's, field's or widget's source, the primary's root
  objects, the same number in an Append), carry only from its findings,
  and triage what the tier then finds. `PageRes`, `Filtered` and
  `PagesNode` keys need their source worked out from their page.
