# B61: After a save, Properties still describes the file as opened

Status: open

- **Found:** 2026-10-26, object streams slice 1 (B3's fix)
- **Where:** `crates/sheaf-app/src/docview.rs` (`properties_context`),
  which reads `doc.model.primary()`; `crates/sheaf-doc/src/properties.rs`
- **Severity:** wrong output
- **What happens:** a save never replaces the primary Source, so after a
  save (Append or Rewrite) File > Properties still shows the opened
  file's size, dates, producer, version, page count, fonts and security.
  Slice 1 fixed only Fast Web View, which now reads the saved record when
  its path is the view's file.
- **Expected:** after a save, Properties describes the file on disk.
- **Repro:** open a PDF, add a mark, save, open Properties: File size is
  the old one.
- **Notes:** the saved `OutputRecord` has the xref facts and the length;
  the info dictionary, fonts and version would need the saved file read
  (or the record extended). See `plan/between/object-streams.md`, slice
  1's notes.
