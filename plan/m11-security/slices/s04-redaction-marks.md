# M11 slice 4: Redaction marks

Status: open · Part of [M11: Security & redaction](../README.md)

**Redaction marks** (decision 4, proposal 5; bug 7).
- `AnnotKind::Redact`.
- Tools:
  - area (drag);
  - text (M9's text selection);
  - Redact Pages… for a range;
  - a key for the tool: Shift+Y, Acrobat's, by M9 decision 13.
- Properties: fill, overlay text (with user presets, like pattern
  presets), font size or auto, repeat, alignment.
- Hatched "not applied" drawing, the Preview toggle, and the bar
  above the page.
- A "Redactions" filter preset in the Comments panel.
- Third-party `/Redact` marks read as editable marks.
- Check: Acrobat applies sheaf's marks and sheaf reads Acrobat's
  (needs reference files; see Asks).
